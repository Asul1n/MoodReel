# 情感分析后端设计说明（成员B）

> 与 **`backend/README.md`** 和**规格 §5** 一致。后端为 Python 服务中枢，承载 TextCNN 推理与中文通道（本地 TextCNN_zh 优先，DeepSeek 在线兜底）。

## 1. 技术栈

| 项 | 选择 |
|----|------|
| 框架 | FastAPI + uvicorn |
| ORM | SQLAlchemy 2.x（SQLite） |
| 英文情感 | **TextCNN**（成员B 训练交付 `models/model.pt`，服务端 `model_runtime/` 前向推理） |
| 中文情感 | **TextCNN_zh 本地优先**（`models/model_zh.pt`，豆瓣星标弱标签训练）+ **DeepSeek 在线兜底**（`services/deepseek.py`，OpenAI 兼容） |
| 热点 | jieba（中文分词）+ 停用词过滤 + 词频（出现评论数）统计 |
| 词云 | `wordcloud` 库后端渲染 PNG（`services/wordcloud_img.py`） |
| 爬虫 | BeautifulSoup（`crawler/`，成员A） |
| 备选 | `services/tencent.py` 腾讯 adapter 保留，**未接入路由** |

## 2. 目录结构（backend/app/）

```
main.py         # FastAPI 入口 + /health（返回 model:{ready,msg}）
config.py       # 读 .env（DB 路径、模型目录、DeepSeek Key、豆瓣反爬池）
db.py           # engine / Base / 会话（含老库自动迁移补列）
models.py       # ORM：movies / reviews / crawl_jobs
schemas.py      # Pydantic 请求/响应
logging_config.py  # 控制台 + 滚动文件日志
routers/        # crawl / dataset / sentiment / hotspot / viz
model_runtime/  # loader / train / zh_kernel（模型定义与训练逐字一致）
services/
  textcnn.py       # 英文：model.pt 加载 + 前向推理（torch 惰性导入）
  textcnn_zh.py    # 中文：model_zh.pt 本地优先（A 方案）
  deepseek.py      # 中文在线兜底：DeepSeek API（可开关 + 优雅降级）
  tencent.py       # 备选腾讯 adapter（未接入）
  nlp.py           # 分词/停用词等基础工具
  analytics.py     # 情感口径统一 + 分布/趋势/热点/褒贬词聚合
  wordcloud_img.py # 词云 PNG 渲染
crawler/        # base / imdb / douban / runner + samples 离线样本
```

## 3. 双通道情感分析

| 通道 | 引擎 | 语言 | 说明 |
|------|------|------|------|
| 本地 | TextCNN | 英文 | 训练/服务共用 `model_runtime/` 模型定义与 vocab，杜绝训练线上不一致 |
| 本地 | TextCNN_zh | 中文 | **优先通道**：`model_zh.pt` 就绪即走本地（免费/离线） |
| 在线 | DeepSeek | 中文 | 本地未就绪时兜底；未配置/超时返回 503 中文错误，主链路不阻塞 |
| 对照 | 多引擎 | 同文本 | `/analyze/compare`：en→TextCNN；zh→TextCNN_zh/DeepSeek |

## 4. 核心数据流

```
爬虫/手动新增 → reviews 落库(source/lang/text)
      → POST /analyze* 按语言路由
      → 回填 pred_label(positive/negative) + pred_prob + model(textcnn/textcnn_zh/deepseek)
      → GET /hotspot、GET /viz/summary 聚合（analytics 统一口径）
```

## 5. 训练与指标（成员B）

- 英文：`scripts/train_textcnn.py` 训练 + 留存集评测（目标准确率 ≥ 85%），产物 `models/model.pt`；当前模型由成员B 训练后单独交付（`model.pt` 不入库）。
- 中文：`scripts/build_zh_dataset.py`（豆瓣星标建弱标签集）+ `scripts/train_textcnn_zh.py` → `models/model_zh.pt`；攒数据用 `scripts/crawl_movies_to_db.py`（批量抓片入库，支持断点续跑）。
- `scripts/benchmark.py`：服务端批量推理计时，**吞吐 ≥ 200 条/秒**。
- 指标在离线/服务端测定写入报告，App 批量分析返回 `throughput` 作现场佐证。
