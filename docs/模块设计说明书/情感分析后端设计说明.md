# 情感分析后端设计说明（成员B）

> 与 **`backend/README.md`** 和**规格 §5** 一致。后端为 Python 服务中枢，承载 TextCNN 推理与腾讯 API 转发。

## 1. 技术栈

| 项 | 选择 |
|----|------|
| 框架 | FastAPI + uvicorn |
| ORM | SQLAlchemy 2.x（SQLite） |
| 英文情感 | **TextCNN**（PyTorch 训练 → 导出 `models/textcnn.npz`，服务端前向推理） |
| 中文情感 | **腾讯 AI 情感 API**（`services/tencent.py` adapter） |
| 热点 | jieba（中文分词）+ TF-IDF/高频词 |
| 爬虫 | BeautifulSoup（`crawler/`，成员A） |

## 2. 目录结构（backend/app/）

```
main.py         # FastAPI 入口 + /health
config.py       # 读 .env（DB 路径、模型目录、腾讯密钥）
db.py           # engine / Base / 会话
models.py       # ORM：movies / reviews / crawl_jobs
schemas.py      # Pydantic 请求/响应
routers/        # crawl / dataset / sentiment / hotspot / viz
services/
  textcnn.py    # 英文：模型加载 + 前向推理（线程池）
  tencent.py    # 中文：腾讯 API adapter（可开关 + 优雅降级）
  nlp.py        # 热点：jieba / TF-IDF / 褒贬倾向词
crawler/        # base / imdb / douban + sample_pack 离线样本
```

## 3. 双通道情感分析

| 通道 | 引擎 | 语言 | 说明 |
|------|------|------|------|
| 本地 | TextCNN | 英文 | 训练/服务共用 tokenizer + vocab.json，杜绝训练线上不一致 |
| 在线 | 腾讯 AI | 中文 | 可开关 + 优雅降级；未配置/超时/配额尽返回中文错误码 |
| 对照 | 双引擎 | 英文同文 | `/analyze/compare` 输出 textcnn 与 tencent 对照 |

## 4. 核心数据流

```
爬虫/手动新增 → reviews 落库(source/lang/text)
      → POST /analyze* 按语言路由
      → 回填 pred_label(positive/negative) + pred_prob + model(textcnn/tencent)
      → GET /hotspot、GET /viz/summary 聚合
```

## 5. 训练与指标（成员B）

- `scripts/train_textcnn.py`：训练 + 留存集评测，**准确率 ≥ 85%**（脚本内置断言）。
- `scripts/benchmark.py`：服务端批量推理计时，**吞吐 ≥ 200 条/秒**。
- 指标在离线/服务端测定写入报告，App 批量分析返回 `throughput` 作现场佐证。
