# 鸿蒙前端设计说明（成员C）

> 与 **`app/README.md`** 和**规格 §5.4** 一致。前端工程整体放 `app/`（DevEco Studio 生成后放入）。本文档为成员C 的前端开发依据。

## 1. 技术栈

| 项 | 选择 |
|----|------|
| 语言 | ArkTS（ArkUI 声明式） |
| IDE | DevEco Studio，Empty Ability，Compatible SDK ≥ API 10 |
| 图表 | **ArkUI Canvas 自绘**（不依赖 ECharts / 第三方图表 SDK） |
| 网络 | `@ohos.net.http` 封装为单一模块 `services/http.ts` |

## 2. 页面规划（5 个 Tab）

| 页签 | 功能 | 主要后端接口 |
|------|------|--------------|
| Tab1 采集 | 选片/输入片名 → 发起抓取 → 轮询进度 → 新增评论 | `POST /crawl`、`GET /crawl/{id}`、`GET /movies`、`POST /dataset/ingest` |
| Tab2 情感 | 批量分析(计数/吞吐)、单条中/英输入、双引擎对照 | `POST /analyze` `/analyze/en` `/analyze/zh` `/analyze/compare` |
| Tab3 热点 | 词云、Top 热点词、褒贬倾向词 | `GET /hotspot` |
| Tab4 可视化 | 环形/条形/趋势图（Canvas 自绘） | `GET /viz/summary` |
| Tab5 设置 | 后端地址、测试连接(`/health`)、腾讯开关 | `GET /health` |

## 3. 模块划分（entry/src/main/ets/）

```
pages/              # 5 个页签 + 详情
services/
  http.ts           # @ohos.net.http 封装（超时/错误码/JSON）
  api.ts            # 接口类型化封装（改后端契约只动这里）
components/
  charts/           # Canvas 自绘：环形/条形/柱状
  wordcloud/        # 加权标签词云排版
model/              # ArkTS 数据类型（与 backend schemas 对齐）
common/             # 常量（默认后端地址）、状态管理
```

## 4. 图表方案（Canvas 自绘）

- **环形图**：正负情感占比；**条形图**：Top 热点词；**柱状图**：褒贬倾向词对比；**趋势线**：按 `created_at` 累计新增评论。
- **词云**：按权重缩放字号的**加权标签排版**（稳定省事），真·螺旋词云列为 stretch 不做承诺。
- 数据来自聚合接口 `GET /viz/summary?context=`（后端一次算好返回，App 只渲染）。

## 5. 关键约定

- 后端地址在**设置页**配置（存 Preferences），默认宿主机局域网 IP；「测试连接」调 `/health`。
- 网络权限：`module.json5` 声明 `ohos.permission.INTERNET`；开发期放开明文 http。
- HTTP 客户端封装成单一模块，便于联调替换与统一报错。
- 分析上下文：`whole`（IMDB 整库）/ `movie:{id}`（某部影片），各页签跟随。
