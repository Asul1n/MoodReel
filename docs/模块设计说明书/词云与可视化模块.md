# 词云与可视化模块

> 与**规格 §5.3（热点挖掘）**、**§5.4（可视化展示）** 一致。热点在 Python 侧算（`services/analytics.py`），图表在前端 ArkTS Canvas 渲染，词云由后端出 PNG。

## 1. 热点挖掘（后端 `services/analytics.py`）

对所选上下文产出三类可解释结果：

| 产出 | 方法 | 返回 |
|------|------|------|
| Top 热点词 | 停用词过滤（英文英文停用词表，中文 jieba + 中文停用词表）+ 按**出现评论数**统计 | `keywords[]` = `{word, weight}` |
| 词云数据 | 与 keywords 同源（按出现评论数加权） | `cloud[]` |
| 褒贬倾向词 | 词在正/负评中的占比差异：正例占比 ≥0.66 归"夸"，≤0.34 归"骂"，至少出现在 2 条评论 | `polarity.pos[]` / `polarity.neg[]` |

> 采用"可解释路线"，不做 LDA 主题模型。情感口径全系统唯一：`COALESCE(pred_label, ground_truth, 豆瓣星级映射)`（≥4 星正 / ≤2 星负 / 3 星不派极性归 unlabeled）。

## 2. 可视化（前端 ArkUI Canvas + 后端词云 PNG）

| 图表 | 数据来源 | 说明 |
|------|----------|------|
| 环形图 | `viz/summary` 的 `dist` | 正/负情感占比 |
| 条形图 | `viz/summary` 的 `top_words` | Top 热点词 |
| 褒贬对比 | `viz/summary` 的 `polarity` | 褒/贬倾向词两列对照 |
| 趋势线 | `viz/summary` 的 `trend` | 按月分桶；时间优先取 `review_time`（评论原始发表时间），缺省回退 `created_at` |
| 词云 | `GET /viz/wordcloud`（PNG） | 后端 `wordcloud` 库渲染，前端 `Image` 直接加载 |

## 3. 接口

```
GET /hotspot?context=&top_n=      → { context, total_reviews, keywords[], cloud[], polarity{pos[],neg[]} }
GET /viz/summary?context=&top_n=  → { dist, trend, top_words, cloud, polarity, by_source, avg_confidence, movie, … }
GET /viz/wordcloud?context=&top_n= → image/png
```

- `context` 取值 `whole`（IMDB 整库）或 `movie:{movie_id}`（某部影片）。
- 后端一次算好返回，App 只渲染，不重复计算。

## 4. 前后端协作

1. 评论经 `analyze` / `analyze/backfill` 回填 `pred_label` 后，热点/可视化接口基于统一口径统计（未打标评论走 ground_truth / 星级映射，旧库也能直接出图）。
2. App 主页各分区按需请求，拿 JSON 交给 `components/charts/`（Canvas）渲染；词云用 `Image` 加载 `/viz/wordcloud` 的 PNG。
3. 词云不做端侧加权排版（原 `components/wordcloud/` 已删），改由后端渲染，稳定性与字体效果都有保证。
