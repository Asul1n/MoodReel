# 词云与可视化模块

> 与**规格 §5.3（热点挖掘）**、**§5.4（可视化展示）** 一致。热点在 Python 侧算，可视化在 ArkTS 侧 Canvas 渲染。

## 1. 热点挖掘（后端 `services/nlp.py`）

对所选上下文产出三类可解释结果：

| 产出 | 方法 | 返回 |
|------|------|------|
| Top 热点词 | 停用词过滤 + TF-IDF / 高频词（英文英文停用词，中文 jieba + 中文停用词） | `keywords[]` |
| 词云数据 | 加权词表 | `cloud[]` = `{word, weight}` |
| 褒贬倾向词 | 词在正/负评中的分布差异（正例占比 lift 或正负 TF-IDF 差） | `polarity_pos[]` / `polarity_neg[]` |

> 采用"可解释路线"，不做 LDA 主题模型。可选缓存 `hotspot_cache`（key = context + topN + hash）避免重复计算。

## 2. 可视化（前端 ArkUI Canvas）

| 图表 | 数据来源 | 说明 |
|------|----------|------|
| 环形图 | `viz/summary` 的 `dist` | 正/负情感占比 |
| 条形图 | `viz/summary` 的 `top_words` | Top 热点词 |
| 柱状图 | `viz/summary` 的 `polarity` | 褒/贬倾向词对比 |
| 趋势线 | `viz/summary` 的 `trend` | 按 `created_at` 累计新增评论 |
| 词云 | `hotspot` 的 `cloud` | 按权重缩放字号的加权标签排版 |

## 3. 接口

```
GET /hotspot?context=&topN=  → { keywords[], polarity_pos[], polarity_neg[], cloud[] }
GET /viz/summary?context=    → { dist, top_words, polarity, trend, … }
```

- `context` 取值 `whole`（IMDB 整库）或 `movie:{movie_id}`（某部影片）。
- 后端一次算好返回，App 只渲染，不重复计算。

## 4. 前后端协作

1. 评论经 `analyze` 回填 `pred_label` 后，热点/可视化接口基于已分析语料统计。
2. App 各页签按需请求，拿 JSON 交给 `components/charts/`（Canvas）与 `components/wordcloud/` 渲染。
3. 词云用加权标签排版（稳定），螺旋布局列为 stretch。
