# 0_总览与导航

> **本文档是 AI 的第一读取文件。** 项目基于 `mood_reel_project` 仓库工作，目录树、技术栈、工作区域划分**以仓库实际结构为准**。遇到问题按「5. 遇到问题去哪里」跳转。

## 1. 项目一句话简介

**MoodReel · 电影评论情感分析系统**（《软件开发实践 2》题目 12）。HarmonyOS App（ArkTS）前端 + Python FastAPI 服务中枢。采集电影评论 → 情感极性分析（英文 TextCNN / 中文腾讯 AI 双通道）→ 热点挖掘（词云 / 褒贬倾向词）→ 多维可视化。

**量化指标**：情感分类准确率 ≥ 85%；系统吞吐 ≥ 200 条/秒（`backend/scripts/benchmark.py` 离线测定）。

## 2. 技术栈总览

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 App | ArkTS + ArkUI（声明式） | DevEco Studio，**Canvas 自绘图表**（非 ECharts） |
| 后端 | Python 3.10+ / FastAPI / SQLAlchemy(SQLite) | REST 服务中枢 |
| 爬虫 | BeautifulSoup | IMDB / 豆瓣双源 + 离线样本兜底 |
| 情感分析 | TextCNN（英文，本地推理）+ 腾讯 AI（中文） | 双通道，可对照 |
| 热点挖掘 | jieba / TF-IDF | 高频词、褒贬倾向词、加权词云 |

## 7. 核心术语表

| 术语 | 含义 |
|------|------|
| 情感标签 pred_label | `positive` / `negative`（**二分类**，无 neutral） |
| 置信度 pred_prob | 0 ~ 1（浮点） |
| 双通道 | 英文 → TextCNN（本地）；中文 → 腾讯 AI；英文可开「对照」再走腾讯 |
| 分析上下文 | `whole`（IMDB 整库）/ `movie:{id}`（某部采集影片） |
| 褒贬倾向词 | 「夸什么 / 骂什么」的正负向关键词 |
| 加权词云 | 按词频/权重缩放的标签词云 |
| model_ready | TextCNN 权重是否已就绪（`/health` 返回） |
| 离线样本兜底 | `crawler/sample_pack/` 内置样本，爬虫不可用时降级（status=degraded） |

## 8. 一致性约定（所有文档共同遵守）

- **API 无 `/api/v1` 前缀**，直接 `/crawl`、`/analyze`、`/hotspot`、`/viz/summary`、`/health` 等（以规格 §6 为准）。
- 后端默认地址 `http://127.0.0.1:8000`，App 侧在设置页可改。
- 数据库三表：`movies` / `reviews` / `crawl_jobs`（详见规格 §4）。
- 情感标签为**二分类** `positive` / `negative`；置信度 `prob` 0~1。
- `movies.movie_id` 为字符串（如 `imdb:tt0111161` / `douban:1292052`）；`reviews.id` 为整型自增。
