# 3_接口契约文档

> 前后端契约以**规格文档 §6** 为基线（唯一真理），字段以 **`backend/app/schemas.py`** 为准。本文档为汇总速查。

## 1. 通用约定

| 项        | 约定                                                  |
| -------- | --------------------------------------------------- |
| Base URL | `http://127.0.0.1:8000`（App 改 `Constants.ets` 的 `BASE_URL`，模拟器/真机用宿主机局域网 IP） |
| API 前缀   | **无**（直接 `/health`、`/crawl`、`/analyze` …）           |
| 数据格式     | JSON（UTF-8）                                         |
| 错误格式     | FastAPI 标准 `{"detail": "中文可读"}` + 合适的 HTTP 状态码      |

## 2. 接口一览（规格 §6）

| 方法 路径                       | 作用                               | 关键入参                                                | 出参要点                                                    |
| --------------------------- | -------------------------------- | --------------------------------------------------- | ------------------------------------------------------- |
| GET /health                 | 探活 + 模型就绪                        | —                                                   | `{ok, model_ready, model:{ready,msg}, version}`         |
| GET /crawl/movies           | 候选影片列表（已采集+离线预置），含简介/海报/评分        | —                                                   | `[movie…]`（含 `available: crawl/offline`，离线含 `note`）   |
| GET /crawl/movie/{movie_id} | 单部影片详情（简介页用）                     | movie_id                                            | `{…元数据, review_count}`                                  |
| POST /crawl                 | 发起抓取（在线成功会顺带写回影片简介等元数据），**201**   | source, query, limit(默认200,≤1000), refresh?         | `{job_id}`                                              |
| GET /crawl/{job_id}         | 任务进度（轮询）                         | —                                                   | `{job_id, status, fetched, limit, error, degraded}`     |
| GET /dataset/stats          | 情感分布统计（按统一口径，context 可切整库/单片）    | context?                                            | `{total, labeled, unlabeled, dist{positive,negative}, by_source}` |
| GET /dataset/reviews        | 浏览/筛选                            | limit, offset, sentiment, source, lang, movie_id, q | `{total, items[]}`                                      |
| POST /dataset/ingest        | 新增/导入评论（**201**）                  | texts[], source?(manual/imdb_static), movie_id?, analyze? | `{ids}`                                            |
| POST /analyze/en            | TextCNN 批量（英文）                   | texts[], lang?                                      | `{results[], count, elapsed_ms, throughput}`            |
| POST /analyze/zh            | 中文批量：本地 TextCNN_zh 优先，未就绪回退 DeepSeek | texts[], lang?                                  | `{results[], count, elapsed_ms, throughput}`            |
| POST /analyze               | 语言自动路由（App 主入口）                  | texts[], lang?                                      | 同上                                                      |
| POST /analyze/backfill      | 给某上下文评论批量补情感标签（整片全流程）            | context, lang?(默认zh), force?, limit?(默认300,≤1000)   | `{context, updated, model, lang}`                       |
| POST /analyze/compare       | 同文本多引擎对照（en→TextCNN；zh→TextCNN_zh/DeepSeek） | text                                    | `{text, lang, textcnn?/textcnn_zh?/deepseek?}`          |
| GET /hotspot                | 热点词/词云数据/褒贬倾向词                   | context, top_n(默认30,≤100)                           | `{context, total_reviews, keywords[], cloud[], polarity{pos[],neg[]}}` |
| GET /viz/summary            | 可视化聚合（一次拿全）                      | context, top_n(默认30)                                | `{dist, trend, top_words, cloud, polarity, by_source, avg_confidence, movie, …}` |
| GET /viz/wordcloud          | **词云 PNG 图片**（前端 `Image` 直接加载）   | context, top_n(默认40,≤100)                           | `image/png`                                             |

## 3. 关键返回结构（对应 schemas.py）

```python
# 单条分析结果（批量接口的 results[] 元素）
AnalyzeItem: { text, lang, model, label, prob, ms }
#   model 实际取值：textcnn / textcnn_zh / deepseek

# 批量分析（/analyze、/analyze/en、/analyze/zh）
AnalyzeBatchOut: { results: AnalyzeItem[], count, elapsed_ms, throughput }

# 评论列表项 / 分页
ReviewOut:      { id, text, lang, source, movie_id, ground_truth, pred_label, pred_prob }
ReviewListOut:  { total, items: ReviewOut[] }

# 探活（实际返回，比 HealthOut 多一个 model 字段）
{ ok, model_ready, model: { ready, msg }, version }

# 影片元数据（/crawl/movies 列表项 与 /crawl/movie/{movie_id} 详情返回）
{ movie_id, title, year, source, source_url,
  intro, poster, rating, genres }   # 详情另含 review_count；列表项另含 available/note
```

> 情感分析统一返回 `{lang, model, label, prob, ms}`；批量再多 `count / elapsed_ms / throughput`。

## 4. 与 App 页面的对应关系

前端落地为 **2 个 Tab**：`TabHome`（单页多分区，承载采集→分析→热点→可视化主流程）与 `TabSettings`（夜间模式 / 采集源）。

| App 区域         | 调用的接口                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------- |
| TabHome 采集区    | `GET /crawl/movies`、`GET /crawl/movie/{id}`（简介/海报）、`POST /crawl`、`GET /crawl/{id}`（轮询）          |
| TabHome 情感区    | `POST /analyze`（批量）、`POST /analyze/backfill`（整片补标）、`GET /dataset/stats`、`GET /dataset/reviews` |
| TabHome 热点区    | `GET /hotspot`（Top 热点词 + 褒贬倾向词）                                                                |
| TabHome 可视化区   | `GET /viz/summary`（环形/条形/趋势）、`GET /viz/wordcloud`（词云 PNG）                                      |
| TabSettings    | 夜间模式 / 采集源切换（本地偏好，不调接口）                                                                       |

## 5. 前端接入现状（`app/mood_reel_GUI/.../services/`）

`api.ets` **已接入真实后端**（不再是 MOCK 模板）：HTTP 统一走 `http.ets` 的 `getText / postText`，`BASE_URL` 集中在 `common/Constants.ets`。函数与接口的对应关系：

| api.ets 函数                            | 真实接口                                                                              |
| ------------------------------------- | --------------------------------------------------------------------------------- |
| `crawlMovie(query, source)`           | `POST /crawl`，body `{source, query, limit:200}` → 取 `job_id`                       |
| `getCrawlStatus(jobId)`               | `GET /crawl/{job_id}`（轮询进度）                                                       |
| `fetchMovies()` / `fetchMovie(id)`    | `GET /crawl/movies` / `GET /crawl/movie/{movie_id}`                               |
| `fetchSentimentDist(context)`         | `GET /dataset/stats?context=…` → 用 `dist`                                         |
| `fetchReviews(movieId)`               | `GET /dataset/reviews?movie_id=…&limit=…`                                         |
| `fetchKeywords()` / `fetchPolarity()` | `GET /hotspot?context=…&top_n=…` → `keywords` / `polarity.{pos,neg}`              |
| `fetchTrend(context)`                 | `GET /viz/summary?context=…` → 取 `trend`                                          |
| `backfill(context)`                   | `POST /analyze/backfill`                                                          |
| 词云（无独立组件）                             | `GET /viz/wordcloud?context=movie:{id}` → **PNG 图片**，`Image` 直接加载                  |

`http.ets` 基于 `@kit.NetworkKit` 的 `http.createHttp()` 封装 GET/POST，统一超时与错误处理。

词云展示（图片 URL 直接给 `Image`）：

```typescript
Image(`${BASE_URL}/viz/wordcloud?context=movie:${movieId}&top_n=40`)
  .width('100%').aspectRatio(1.6).objectFit(ImageFit.Contain)
```

要点：`BASE_URL` 联调填宿主机局域网 IP；需 INTERNET 权限 + http 明文放开（见 `app/README.md`）。
