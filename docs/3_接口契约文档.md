# 3_接口契约文档

> 前后端契约以**规格文档 §6** 为基线（唯一真理），字段以 **`backend/app/schemas.py`** 为准。本文档为汇总速查。

## 1. 通用约定

| 项        | 约定                                                  |
| -------- | --------------------------------------------------- |
| Base URL | `http://127.0.0.1:8000`（App 设置页可配，模拟器/真机用宿主机局域网 IP） |
| API 前缀   | **无**（直接 `/health`、`/crawl`、`/analyze` …）           |
| 数据格式     | JSON（UTF-8）                                         |
| 错误格式     | `{ "code": ..., "message": "中文可读" }` + 合适的 HTTP 状态码 |

## 2. 接口一览（规格 §6）

| 方法 路径                       | 作用                               | 关键入参                                                | 出参要点                                                    |
| --------------------------- | -------------------------------- | --------------------------------------------------- | ------------------------------------------------------- |
| GET /health                 | 探活 + 模型就绪                        | —                                                   | `{ok, model_ready, version}`                            |
| GET /crawl/movies           | 影片列表（已采集+离线预置），含简介/海报/评分         | source?                                             | `[movie…]`                                              |
| GET /crawl/movie/{movie_id} | 单部影片详情（简介页用）                     | movie_id                                            | `{…元数据, review_count}`                                  |
| POST /crawl                 | 发起抓取（在线成功会顺带写回影片简介等元数据）          | source, query/movie_id, limit                       | `{job_id}`                                              |
| GET /crawl/{job_id}         | 任务进度（轮询）                         | —                                                   | `{status, fetched, limit, error, degraded}`             |
| GET /dataset/stats          | 情感分布统计（按统一口径，context 可切整库/单片）    | context?                                            | `{total, dist{positive,negative,neutral}, by_source}`   |
| GET /dataset/reviews        | 浏览/筛选                            | limit, offset, sentiment, source, lang, movie_id, q | 分页列表                                                    |
| POST /dataset/ingest        | 新增/导入评论                          | text/texts, source?, analyze?                       | `{id}` / `{ids}`                                        |
| POST /analyze/en            | TextCNN 批量（英文）                   | texts[]                                             | `{results[], count, elapsed_ms, throughput}`            |
| POST /analyze/zh            | DeepSeek（中文，未配置回退百度）             | texts[]                                             | `{results[]}`                                           |
| POST /analyze               | 语言自动路由                           | texts[]                                             | `{results[]}`                                           |
| POST /analyze/backfill      | 给某上下文评论批量打标签（整片全流程）              | context, lang?, force?, limit?                      | `{updated, model}`                                      |
| POST /analyze/compare       | 同文本多引擎对照（en→TextCNN；zh→DeepSeek） | text                                                | `{textcnn?/deepseek?/baidu?}`                           |
| GET /hotspot                | 热点词/褒贬词/词云数据                     | context, topN                                       | `{keywords[], polarity_pos[], polarity_neg[], cloud[]}` |
| GET /viz/summary            | 可视化聚合                            | context                                             | `{dist, top_words, polarity, trend, …}`                 |
| GET /viz/wordcloud          | **词云 PNG 图片**（前端 `Image` 直接加载）   | context, topN                                       | `image/png`                                             |

## 3. 关键返回结构（对应 schemas.py）

```python
# 单条分析结果（批量接口的 results[] 元素）
AnalyzeItem: { text, lang, model, label, prob, ms }

# 批量分析（/analyze/en 等）
AnalyzeBatchOut: { results: AnalyzeItem[], count, elapsed_ms, throughput }

# 评论列表项 / 分页
ReviewOut:      { id, text, lang, source, movie_id, ground_truth, pred_label, pred_prob }
ReviewListOut:  { total, items: ReviewOut[] }

# 探活
HealthOut:      { ok, model_ready, version }

# 影片元数据（/crawl/movies 列表项 与 /crawl/movie/{movie_id} 详情返回）
MovieMeta:      { movie_id, title, year, source, source_url,
                  intro, poster, rating, genres }   # 详情另含 review_count
```

> 情感分析统一返回 `{lang, model, label, prob, ms}`；批量再多 `count / elapsed_ms / throughput`。

## 5. 前端接入指南：把 MOCK 换成真实 HTTP（改 `app/.../services/api.ets`）

当前 `api.ets` 是模板版（每个函数 `TODO` + 返回 MOCK 数据），联调前需改成真调后端。对应关系与示例：

| api.ets 函数                            | 真实接口                                                                              |
| ------------------------------------- | --------------------------------------------------------------------------------- |
| `crawlMovie(query, source)`           | `POST /crawl`，body `{source, query, limit}` → 取 `job_id` 轮询 `GET /crawl/{job_id}` |
| `fetchSentimentDist()`                | `GET /dataset/stats?context=movie:{id}` → 用 `dist`                                |
| `fetchReviews()`                      | `GET /dataset/reviews?movie_id={id}&limit=…`                                      |
| `fetchKeywords()` / `fetchPolarity()` | `GET /hotspot?context=movie:{id}&top_n=…` → `keywords` / `polarity.{pos,neg}`     |
| `fetchTrend()`                        | `GET /viz/summary?context=…` → 取 `trend`                                          |
| 词云（原组件已删）                             | `GET /viz/wordcloud?context=movie:{id}` → **PNG 图片**                              |

示例（ArkTS `@ohos.net.http`）：

```typescript
import { http } from '@kit.NetworkKit';

export function getJSON(path: string, onDone: (code: number, body: string) => void): void {
  const req = http.createHttp();
  req.request(BASE_URL + path, { method: http.RequestMethod.GET }, (err, data) => {
    onDone(err ? -1 : data.responseCode, err ? '' : data.result as string);
    req.destroy();
  });
}
```

词云展示（图片 URL 直接给 `Image`）：

```typescript
Image(`${BASE_URL}/viz/wordcloud?context=movie:${movieId}&top_n=40`)
  .width('100%').aspectRatio(1.6).objectFit(ImageFit.Contain)
```

要点：`BASE_URL` 联调填宿主机局域网 IP；请求前先 `Image` 需 INTERNET 权限 + http 明文放开（见 `app/README.md`）。
