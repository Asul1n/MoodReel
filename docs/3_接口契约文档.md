# 3_接口契约文档

> 前后端契约以 **规格文档 §6** 与 **`backend/app/schemas.py`** 为唯一真理。本文档供直接联调。

## 1. 通用约定

| 项 | 约定 |
|---|---|
| Base URL | `http://127.0.0.1:8000`（App 设置页可配；模拟器/真机填宿主机局域网 IP） |
| 数据接口返回 | **JSON（UTF-8）** |
| 图片接口返回 | **二进制图片流**：词云 `image/png`；本地海报 `image/jpeg` |
| 错误 | 数据接口返回 `{ "code": …, "message": "中文可读" }` + HTTP 状态码 |
| 抓取默认 | `POST /crawl` 不传 `limit` 时默认 **200** 条/部（上限 1000；豆瓣按 hot+time 多排序并集去重抓取） |

**情感口径（全局统一，中英文一致）**：只有两档 `positive / negative`，中性/犹豫用**低置信度**表达（`prob` 越接近 0.5 越中性）；无标签评论记为 `unlabeled`（不入正负）。

## 2. 接口一览

| 方法 路径 | 作用 | 关键入参 | 返回要点 |
|---|---|---|---|
| GET /health | 探活 + 模型就绪 | — | `{ok, model_ready, model:{ready,msg}, version}` |
| GET /crawl/movies | 影片列表（已采集+离线预置） | `source?` | `[MovieMeta…]`，`available` |
| GET /crawl/movie/{movie_id} | 单部影片详情（简介页） | `movie_id` | `MovieMeta + review_count` |
| POST /crawl | 发起抓取；**已有评论则复用跳过重抓**（`refresh=true` 强制） | `{source, query, limit=200, refresh=false}` | `{job_id}`（done 时 `fetched`=复用条数） |
| GET /crawl/{job_id} | 任务进度（轮询） | — | `{status, fetched, limit, error, degraded}` |
| GET /dataset/stats | 情感分布（二类） | `context?` | `{context,total,labeled,unlabeled,dist,by_source}` |
| GET /dataset/reviews | 浏览/筛选评论 | `limit,offset,sentiment,source,lang,movie_id,q` | `{total, items:[ReviewOut…]}` |
| POST /dataset/ingest | 手动新增/导入评论 | `{texts[], source='manual', movie_id?, analyze=false}` | `{ids[], count, analyze}` |
| POST /analyze/en | 英文批量 → 本地 TextCNN（二类） | `{texts[], lang}` | `{results:[AnalyzeItem…], count, elapsed_ms, throughput}` |
| POST /analyze/zh | **中文 → DeepSeek**（唯一中文通道，二类+置信度） | `{texts[]}` | 同上 |
| POST /analyze | 语言自动路由（App 主入口） | `{texts[], lang?}` | 同上（zh/en 自动判定） |
| POST /analyze/backfill | 给某上下文评论批量打标（整片全流程） | `{context, lang='zh', force=false, limit=300}` | `{updated, model='deepseek'}` |
| POST /analyze/compare | 同文本多引擎对照 | `{text}` | `{text, lang, textcnn?/deepseek?}` |
| GET /hotspot | 热点词 / 褒贬词 | `context, top_n` | `{context,total_reviews,keywords,cloud,polarity:{pos,neg}}` |
| GET /viz/summary | 可视化聚合（一次拿全） | `context, top_n` | 见 §4 |
| GET /viz/wordcloud | 词云 PNG 图片（返回图片流） | `context, top_n` | `image/png` |

**`context`**：`whole`（全库/IMDB 静态）或 `movie:{movie_id}`。

## 3. 返回结构与字段语义

```python
# 单条情感结果（/analyze* 的 results[] 元素）
AnalyzeItem: { text, lang, model, label, prob, ms }
AnalyzeBatchOut: { results: [AnalyzeItem], count, elapsed_ms, throughput }

ReviewOut:  { id, text, lang, source, movie_id, ground_truth, pred_label, pred_prob }
ReviewListOut: { total, items: [ReviewOut] }

HealthOut: { ok, model_ready, model, version }

MovieMeta: { movie_id, title, year, source, source_url,
             intro, poster, rating, genres }        # 详情另含 review_count
```

| 字段 | 含义 |
|---|---|
| `label` | **只有 `positive / negative`**（中英文一致）；无 neutral 档 |
| `prob` | 置信度/方向强度 **0~1**：≈0.5 表示偏中性/犹豫，≈1 表示情感很强。**仅模型判定有值**；星级/ground_truth 等人工标签为 NULL |
| `ground_truth` | 评论的"标准答案"（权威标签，IMDB 静态语料自带），用于评测模型；实时爬的评论一般无 |
| `unlabeled` | 完全无标签或"中性(如豆瓣 3 星)"未派极性的评论，单独统计，不入 `dist` |
| `model` | `textcnn`（英文本地）/ `deepseek`（中文）/ `static` / `stars` |

**统一口径**：
```
label = pred_label  →  ground_truth  →  豆瓣星级(≥4 正 / ≤2 负；3 星不派，归 unlabeled)  →  无则 unlabeled
```

## 4. 聚合接口返回样例（真实）

### GET /dataset/stats?context=movie:douban:1889243
```json
{ "context": "movie:douban:1889243", "total": 60, "labeled": 60, "unlabeled": 0,
  "dist": {"positive": 43, "negative": 17},
  "by_source": {"douban_live": 60} }
```

### GET /viz/summary?context=…
```json
{ "context": "…", "movie": {"movie_id": "douban:1889243", "title": "星际穿越", "rating": 9.4,
    "poster": "/static/posters/douban_1889243.jpg", "review_count": 60},
  "total": 60, "dist": {"positive": 43, "negative": 17},
  "avg_confidence": 0.776,
  "trend": [ {"date": "2014-11", "total": 53, "positive": 39, "negative": 14}, … ],
  "top_words": [{"word": "诺兰", "weight": 5}, …],
  "cloud": [{"word": "…", "weight": …}],
  "polarity": {"pos": [{"word": "黑洞", "weight": …}], "neg": [{"word": "可惜", "weight": …}]} }
```
- `trend`：**按月**聚合（`date` 形如 `2014-11`，横轴"年份-月"），做"随时间变好变坏"图；`total` 含未标注
- `avg_confidence`：该上下文内模型预测置信度的均值（`prob` 均值）；无预测则为 null
- 置信度低（~0.5）的评论即"中性/模棱两可"，前端可用置信度做深浅/灰显

### GET /hotspot?context=…&top_n=20
```json
{ "context": "…", "total_reviews": 60,
  "keywords": [{"word": "诺兰", "weight": 12}, …],
  "cloud": [ … ],
  "polarity": {"pos": [{"word": "黑洞", "weight": …}],
               "neg": [{"word": "可惜", "weight": …}]} }
```

## 5. 图片与静态资源规范（海报 / 词云）

**海报 poster（JSON 里给"地址"）**
- 后端把豆瓣海报下载到本地伺服（规避防盗）：本地 `poster="/static/posters/{movie_id}.jpg"`（以 `/` 开头）；下载失败兜底为豆瓣外链 `https://…`
- 前端：
```typescript
Image(poster.startsWith('/') ? BASE_URL + poster : poster)
```

**词云 /viz/wordcloud（非 JSON，直接 PNG 字节）**
```typescript
Image(`${BASE_URL}/viz/wordcloud?context=movie:${movieId}&top_n=40`)
  .width('100%').aspectRatio(1.6).objectFit(ImageFit.Contain)
```

## 7. 前端接入：把 MOCK 换成真实 HTTP（改 `api.ets`）

| api.ets 函数 | 真实接口 |
|---|---|
| `crawlMovie(query, source)` | `POST /crawl` body `{source,query,limit:200}` → 轮询 `GET /crawl/{job_id}` |
| `fetchSentimentDist()` | `GET /dataset/stats?context=movie:{id}` → `dist` |
| `fetchReviews()` | `GET /dataset/reviews?movie_id={id}&limit=…` |
| `fetchKeywords()` / `fetchPolarity()` | `GET /hotspot?context=movie:{id}` → `keywords` / `polarity.{pos,neg}` |
| `fetchTrend()` | `GET /viz/summary?context=…` → `trend` |
| 词云 | `GET /viz/wordcloud?context=…` → PNG |

HTTP 示例（ArkTS）：
```typescript
import { http } from '@kit.NetworkKit';
export function getJSON(path: string, onDone: (code: number, body: string) => void): void {
  const req = http.createHttp();
  req.request(BASE_URL + path, { method: http.RequestMethod.GET }, (err, data) => {
    onDone(err ? -1 : data.responseCode, err ? '' : data.result as string);
    req.destroy();
  });
}
```
联调必做：`ohos.permission.INTERNET`、http 明文放开、`BASE_URL` 填宿主机局域网 IP。

## 8. 排错速查

| 现象 | 处理 |
|---|---|
| `/health` `model_ready=false` | `model.msg`：装 torch / 放 `model.pt` |
| `/analyze/zh`、`/backfill` 503 | `.env` 配 `DEEPSEEK_API_KEY` 并 `DEEPSEEK_ENABLED=true` |
| 抓取 `degraded` | 反爬/断网走离线样本 |
| 词云打不开 | 后端是否起、URL 是否拼了 BASE_URL、INTERNET+明文权限 |
