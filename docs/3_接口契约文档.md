| 项        | 约定                                                  |
| -------- | --------------------------------------------------- |

## 2. 接口一览（规格 §6）

| 方法 路径                       | 作用                               | 关键入参                                                | 出参要点                                                    |
| --------------------------- | -------------------------------- | --------------------------------------------------- | ------------------------------------------------------- |
| GET /health                 | 探活 + 模型就绪                        | —                                                   | `{ok, model_ready, model:{ready,msg}, version}`         |
| GET /crawl/movies           | 候选影片列表（已采集+离线预置），含简介/海报/评分        | —                                                   | `[movie…]`（含 `available: crawl/offline`，离线含 `note`）   |
| GET /crawl/movie/{movie_id} | 单部影片详情（简介页用）                     | movie_id                                            | `{…元数据, review_count}`                                  |
| POST /crawl                 | 发起抓取（在线成功会顺带写回影片简介等元数据），**201**   | source, query, limit(默认200,≤1000), refresh?         | `{job_id}`                                              |
| GET /crawl/{job_id}         | 任务进度（轮询）                         | —                                                   | `{job_id, status, fetched, limit, error, degraded}`     |
| GET /dataset/stats          | 情感分布统计（按统一口径，context 可切整库/单片）    | context?                                            | `{total, labeled, unlabeled, dist{positive,negative}, by_source}` |

| POST /dataset/ingest        | 新增/导入评论（**201**）                  | texts[], source?(manual/imdb_static), movie_id?, analyze? | `{ids}`                                            |
| POST /analyze/en            | TextCNN 批量（英文）                   | texts[], lang?                                      | `{results[], count, elapsed_ms, throughput}`            |
| POST /analyze/zh            | 中文批量：本地 TextCNN_zh 优先，未就绪回退 DeepSeek | texts[], lang?                                  | `{results[], count, elapsed_ms, throughput}`            |
| POST /analyze               | 语言自动路由（App 主入口）                  | texts[], lang?                                      | 同上                                                      |
| POST /analyze/backfill      | 给某上下文评论批量补情感标签（整片全流程）            | context, lang?(默认zh), force?, limit?(默认300,≤1000)   | `{context, updated, model, lang}`                       |
| POST /analyze/compare       | 同文本多引擎对照（en→TextCNN；zh→TextCNN_zh/DeepSeek） | text                                    | `{text, lang, textcnn?/textcnn_zh?/deepseek?}`          |
| GET /hotspot                | 热点词/词云数据/褒贬倾向词                   | context, top_n(默认30,≤100)                           | `{context, total_reviews, keywords[], cloud[], polarity{pos[],neg[]}}` |
| GET /viz/summary            | 可视化聚合（一次拿全）                      | context, top_n(默认30)                                | `{dist, trend, top_words, cloud, polarity, by_source, avg_confidence, movie, …}` |
| GET /viz/wordcloud          | **词云 PNG 图片**（前端 `Image` 直接加载）   | context, top_n(默认40,≤100)                           | `image/png`                                             |
| POST /auth/register         | 用户注册（用户名+密码）                  | username, password                                    | **201** `{user_id, username, created_at}`；用户名重复 **409** `{"detail": "用户名已存在"}` |
| POST /auth/login            | 登录，签发 token                       | username, password                                    | `{token, user:{user_id, username}}`；凭据错误 **401** `{"detail": "用户名或密码错误"}` |
| GET /auth/me                | 当前登录用户信息（已实现，前端暂未调用）     | Header `Authorization: Bearer <token>`                | `{user_id, username, created_at}`；token 无效/过期 **401**   |
| POST /auth/logout           | 退出登录，使 token 失效（已实现，前端本地清 token） | Header 同上                                     | `{ok: true}`                                            |
| GET /recommend              | **为你推荐**（登录→个性化；游客/无画像→热点兜底） | limit(默认6,≤20) + Header 可选 token                  | `{mode, items[]}`，见「推荐约定」                        |

**用户认证约定（2026-10 新增）**：

- 字段口径与前端校验一致：`username` 3~20（中文/字母/数字/下划线，不含空格，后端按 **UTF-8 字节** 计，故 1~6 个汉字）、`password` 6~20 位；后端再校验一遍，错误返回 400 `{"detail": "…"}`。
- token：服务端生成（`secrets.token_hex(32)`）存 `users.token`，有效期 7 天（`token_expires_at`），**新登录顶掉旧 token**（单设备在线）。
- 密码：服务端**加盐哈希**存储（标准库 `pbkdf2_hmac('sha256')`，20 万轮，格式 `pbkdf2_sha256$轮数$salt$hash`，恒时比较校验；无第三方依赖），任何接口不得返回 password 相关字段。
- 鉴权范围：`/auth` 之外的业务接口**不强制鉴权**（游客模式，主流程全可用）；仅 `POST /crawl` 与 `GET /recommend` 会读取有效 token（前者记搜索行为、后者出个性化推荐），token 无效时按游客处理、**不报 401**。
- **实现状态（2026-10-28）**：`/auth/register`、`/auth/login`、`/auth/me`、`/auth/logout` 四个接口均已落地（`app/routers/auth.py`，哈希与 token 逻辑在 `app/services/auth.py`），`/auth/me` 与 `/auth/logout` 虽为契约中的"可选实现"也已提供，前端可择机接入。
- 联调在内网明文 http 下进行（与现有接口一致），报告注明生产环境须 https。

**推荐约定（2026-10 新增，`GET /recommend`）**：

- **响应结构**：`{ "mode": "personalized" | "hot", "items": [...] }`；`items` 元素：`{ movie_id, title, poster, rating, genres, reason }`，其中 `reason` 为推荐理由文案——`personalized` 模式返回命中的标签（如 `"科幻 ×2 · 冒险 ×1"`），`hot` 模式返回 `"近期热门"`（或空串，前端有默认文案）。
- **鉴权与降级**：请求可带可不带 token；**token 无效/过期不报 401**，直接按游客降级为 `hot` 模式（推荐是非关键功能，优雅降级）。
- **用户画像算法**（Python 侧实时聚合，不建画像表）：
  1. 取该用户 `search_events` 中的影片集合（**同一影片去重，只计一次**）；
  2. 对每部影片的 `genres` 拆分标签（兼容 `/` 与 `,` 两种分隔符，返回给前端时统一为 ` / ` 分隔）；
  3. 标签权重归一：每部影片的每个标签贡献 `1/标签数`（避免"剧情"等大众标签主导画像）；
  4. 用户标签向量 = 所有已看影片标签贡献求和；
  5. 候选打分：未搜索过的影片，得分 = 其各标签在用户向量中的权重之和，降序取前 `limit` 部；
  6. **冷启动**（无搜索记录或得分全 0）→ `mode: "hot"`，按 `review_count` 降序（并列取最新 `created_at`）取前 `limit` 部；
  7. 片库不足时 `items` 可少于 `limit`，允许为空数组（前端有空态兜底）。
- **搜索行为记录**：**不新增上报接口**——后端在 `POST /crawl` 处理成功且匹配到影片时，若请求带有效 token 则自动写一条 `search_events(user_id, movie_id, keyword)`；游客不记录。
- **可解释性**：`reason` 直接展示在前端推荐卡片上（"因为你看过多部科幻片"的依据），作为本模块的答辩演示点。

## 3. 关键返回结构（对应 schemas.py）

```python
# 单条分析结果（批量接口的 results[] 元素）
AnalyzeItem: { text, lang, model, label, prob, ms }
#   model 实际取值：textcnn / textcnn_zh / deepseek

# 批量分析（/analyze、/analyze/en、/analyze/zh）
AnalyzeBatchOut: { results: AnalyzeItem[], count, elapsed_ms, throughput }

# 评论列表项 / 分页
ReviewOut:      { id, text, lang, source, movie_id, ground_truth, pred_label, pred_prob }
ReviewListOut:  { total, items: ReviewOut[] }

# 探活（实际返回，比 HealthOut 多一个 model 字段）
{ ok, model_ready, model: { ready, msg }, version }

# 影片元数据（/crawl/movies 列表项 与 /crawl/movie/{movie_id} 详情返回）
{ movie_id, title, year, source, source_url,
  intro, poster, rating, genres }   # 详情另含 review_count；列表项另含 available/note

# 用户认证（/auth/register 201 返回 / /auth/login 返回）
RegisterOut: { user_id, username, created_at }
LoginOut:    { token, user: { user_id, username } }
# 错误：409 用户名已存在；401 用户名或密码错误；401 token 无效/过期（前端据此提示，本地登录态为空即视为游客）

# 推荐（GET /recommend，mode: personalized / hot）
RecommendItem: { movie_id, title, poster, rating, genres, reason }
RecommendOut:  { mode, items: RecommendItem[] }
# genres 统一 " / " 分隔；reason 个性化模式为命中标签（"科幻 ×2 · 冒险 ×1"），hot 模式为 "近期热门" 或空串
```

> 情感分析统一返回 `{lang, model, label, prob, ms}`；批量再多 `count / elapsed_ms / throughput`。

## 4. 与 App 页面的对应关系

前端落地为 **2 个 Tab**：`TabHome`（单页多分区，承载采集→分析→热点→可视化主流程）与 `TabSettings`（夜间模式 / 采集源）。

| App 区域         | 调用的接口                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------- |
| 设置页用户卡片 / 登录注册页（AuthPage） | `POST /auth/register`、`POST /auth/login`（游客模式：主流程不强制登录）                                |
| TabHome 推荐区（「为你推荐」横滑卡片，点卡片直达分析） | `GET /recommend`（登录个性化 / 游客热点，token 无效自动降级 hot）                               |
| TabHome 采集区    | `GET /crawl/movies`、`GET /crawl/movie/{id}`（简介/海报）、`POST /crawl`、`GET /crawl/{id}`（轮询）          |
| TabHome 情感区    | `POST /analyze/backfill`（整片补标）、`GET /dataset/stats`、`GET /dataset/reviews` |
| TabHome 热点区    | `GET /hotspot`（Top 热点词 + 褒贬倾向词）                                                                |
| TabHome 可视化区   | `GET /viz/summary`（环形/条形/趋势）、`GET /viz/wordcloud`（词云 PNG）                                      |
| TabSettings    | 夜间模式 / 采集源切换（本地偏好，不调接口）                                                                       |

## 5. 前端接入现状（`app/mood_reel_GUI/.../services/`）

`api.ets` **已接入真实后端**（不再是 MOCK 模板）：HTTP 统一走 `http.ets` 的 `getText / postText`，`BASE_URL` 集中在 `common/Constants.ets`。函数与接口的对应关系：

| api.ets 函数                            | 真实接口                                                                              |
| ------------------------------------- | --------------------------------------------------------------------------------- |
| `crawlMovie(query, source)`           | `POST /crawl`，body `{source, query, limit:200}` → 取 `job_id`                       |
| `getCrawlStatus(jobId)`               | `GET /crawl/{job_id}`（轮询进度）                                                       |
| `fetchMovies()` / `fetchMovie(id)`    | `GET /crawl/movies` / `GET /crawl/movie/{movie_id}`                               |
| `fetchSentimentDist(context)`         | `GET /dataset/stats?context=…` → 用 `dist`                                         |
| `fetchReviews(movieId)`               | `GET /dataset/reviews?movie_id=…&limit=…`                                         |
| `fetchKeywords(context)` / `fetchPolarity(context)` | `GET /hotspot?context=…&top_n=…` → `keywords` / `polarity.{pos,neg}`              |
| `fetchTrend(context)`                 | `GET /viz/summary?context=…` → 取 `trend`                                          |
| `backfill(context)`                   | `POST /analyze/backfill`                                                          |
| `registerAuth(username, password)`    | `POST /auth/register`（用户名重复报 409，前端展示 detail）                                     |
| `loginAuth(username, password)`       | `POST /auth/login` → 存 `AppStorage['authToken'/'authUsername']`（持久化）               |
| `fetchRecommend(limit)`               | `GET /recommend?limit=…` → 主页「为你推荐」卡片流（mode=hot 时前端显示热点文案）                        |
| 词云（无独立组件）                             | `GET /viz/wordcloud?context=movie:{id}` → **PNG 图片**，`Image` 直接加载                  |

`http.ets` 基于 `@kit.NetworkKit` 的 `http.createHttp()` 封装 GET/POST，统一超时与错误处理。

词云展示（图片 URL 直接给 `Image`）：

```typescript
Image(`${getBaseUrl()}/viz/wordcloud?context=movie:${movieId}&top_n=40`)
  .width('100%').aspectRatio(1.6).objectFit(ImageFit.Contain)
```

要点：`getBaseUrl()` 读取 `AppStorage['baseUrl']`（设置页改地址后立即生效，`PersistentStorage` 持久化）；需 INTERNET 权限 + http 明文放开（见 `app/README.md`）。
