# 3_接口契约文档（详细版）

> 前后端契约以 **规格文档 §6** 与 **`backend/app/schemas.py`** 为唯一真理，本文档为**可直接照着联调**的速查。

## 1. 通用约定

| 项 | 约定 |
|---|---|
| Base URL | `http://127.0.0.1:8000`（App 设置页可配；模拟器/真机用宿主机局域网 IP，如 `http://192.168.10.183:8000`） |
| 数据接口返回 | **JSON（UTF-8）** |
| 图片接口返回 | **二进制图片流**（见 §5）：词云 `image/png`；本地海报 `image/jpeg` |
| 错误 | 数据接口返回 `{ "code": …, "message": "中文可读" }` + HTTP 状态码（4xx/5xx） |
| 抓取默认 | `POST /crawl` 不传 `limit` 时默认 **200** 条/部（上限 500） |

## 2. 接口一览

| 方法 路径 | 作用 | 关键入参 | 返回要点 |
|---|---|---|---|
| GET /health | 探活 + 模型就绪 | — | `{ok, model_ready, model:{ready,msg}, version}` |
| GET /crawl/movies | 影片列表（已采集 + 离线预置），含简介/海报/评分 | `source?` | `[MovieMeta…]`，`available: crawl\|offline` |
| GET /crawl/movie/{movie_id} | 单部影片详情（简介页） | `movie_id` | `MovieMeta + review_count` |
| POST /crawl | 发起抓取（成功后顺带写回简介/海报/评分，并下载海报到本地） | `{source, query, limit=200}` | `{job_id}` |
| GET /crawl/{job_id} | 任务进度（轮询） | — | `{status, fetched, limit, error, degraded}` |
| GET /dataset/stats | 情感分布 | `context?` | `{context,total,labeled,unlabeled,dist,by_source}` |
| GET /dataset/reviews | 浏览/筛选评论 | `limit,offset,sentiment,source,lang,movie_id,q` | `{total, items:[ReviewOut…]}` |
| POST /dataset/ingest | 手动新增/导入评论 | `{texts[], source='manual', movie_id?, analyze=false}` | `{ids[], count, analyze}` |
| POST /analyze/en | 英文批量 → 本地 TextCNN | `{texts[], lang}` | `{results:[AnalyzeItem…], count, elapsed_ms, throughput}` |
| POST /analyze/zh | 中文 → DeepSeek（未配置回退百度） | `{texts[]}` | 同上 |
| POST /analyze | 语言自动路由（App 主入口） | `{texts[], lang?}` | 同上（zh/en 按文本自动判定） |
| POST /analyze/backfill | 给某上下文评论批量打标（整片全流程） | `{context, lang='zh', force=false, limit=300}` | `{updated, model='deepseek'}` |
| POST /analyze/compare | 同文本多引擎对照 | `{text}` | `{text, lang, textcnn?/deepseek?/baidu?}` |
| GET /hotspot | 热点词 / 褒贬词 / 词云数据 | `context, top_n` | `{context,total_reviews,keywords,cloud,polarity:{pos,neg}}` |
| GET /viz/summary | 可视化聚合（一次拿全） | `context, top_n` | `{movie, total, dist, avg_confidence, trend, top_words, cloud, polarity, …}` |
| GET /viz/wordcloud | **词云 PNG 图片**（直接返回图片流） | `context, top_n` | `image/png` |

**`context` 取值**：`whole`（全库/IMDB 静态）或 `movie:{movie_id}`（某部采集影片，如 `movie:douban:1889243`）。

## 3. 关键返回结构（对应 schemas.py）

```python
# 单条情感结果（/analyze* 的 results[] 元素）
AnalyzeItem: { text, lang, model, label, prob, ms }
# 批量分析
AnalyzeBatchOut: { results: [AnalyzeItem], count, elapsed_ms, throughput }

# 评论列表项
ReviewOut:  { id, text, lang, source, movie_id, ground_truth, pred_label, pred_prob }
ReviewListOut: { total, items: [ReviewOut] }

# 探活
HealthOut: { ok, model_ready, model, version }

# 影片元数据（/crawl/movies 项 与 /crawl/movie/{id} 返回）
MovieMeta: { movie_id, title, year, source, source_url,
             intro, poster, rating, genres }        # 详情另含 review_count
```

### 字段语义（重要）

| 字段 | 含义 |
|---|---|
| `label` | `positive / negative / neutral`。**TextCNN(英文)恒二分类，只有 pos/neg**；`neutral` 仅来自中文模型(DeepSeek/百度)或豆瓣 3 星 |
| `prob` | 置信度 0~1（取两个概率里大的）。**仅模型判定有值**；星级/ground_truth 这类人工标签没有概率（`pred_prob=NULL`） |
| `ground_truth` | 评论的"标准答案"（权威标签）：IMDB 静态语料自带 pos/neg，用来**评测模型准确率**；实时爬的评论一般无。分析口径里它也是兜底来源之一 |
| `model` | 打标签引擎：`textcnn`（英文本地）/ `deepseek`（中文默认）/ `baidu`/`static`/`stars` |
| `unlabeled` | 完全无标签的评论（不算 neutral，单独统计） |
| `review_time` | 评论**原始发表时间**（DB 字段，趋势图按此分桶） |

### 情感统一口径（dist/图表都按此）
```
label = pred_label  →  ground_truth  →  豆瓣星级映射(≥4 正 / =3 中 / ≤2 负)  →  无则 unlabeled
```

## 4. 几个聚合接口的返回样例（真实）

### GET /dataset/stats?context=movie:douban:1889243
```json
{ "context": "movie:douban:1889243", "total": 60, "labeled": 60, "unlabeled": 0,
  "dist": {"positive": 37, "negative": 16, "neutral": 7},
  "by_source": {"douban_live": 60} }
```

### GET /viz/summary?context=…
```json
{ "context": "…", "movie": {"movie_id": "douban:1889243", "title": "星际穿越", "rating": 9.4,
    "poster": "/static/posters/douban_1889243.jpg", "review_count": 60},
  "total": 60, "dist": {"positive": 37, "negative": 16, "neutral": 7},
  "avg_confidence": 0.825,
  "trend": [ {"date": "2014-11-05", "total": 1, "positive": 1, "negative": 0, "neutral": 0}, … ],
  "top_words": [{"word": "诺兰", "weight": 5}, …],
  "cloud": [{"word": "…", "weight": …}],
  "polarity": {"pos": [{"word": "黑洞", "weight": …}], "neg": [{"word": "可惜", "weight": …}]} }
```
- `trend`：按评论**原始发表时间**逐日分桶（非入库时间），做"随时间变好变坏"折线/柱状图
- `avg_confidence`：该上下文里所有模型预测 `pred_prob` 的均值（无模型预测则为 null）

### GET /hotspot?context=…&top_n=20
```json
{ "context": "…", "total_reviews": 60,
  "keywords": [{"word": "自由", "weight": 12}, …],     // 全评论高频词
  "cloud": [ … 同 keywords … ],                        // 词云权重词表
  "polarity": {"pos": [{"word": "安迪", "weight": …}],  // "观众夸什么"
               "neg": [{"word": "大众", "weight": …}]} } // "观众骂什么"
```

## 5. 图片与静态资源规范（海报 / 词云）

**海报 poster（JSON 里给"地址"，分两种）**
- 后端爬取时把豆瓣海报**下载到本地**并伺服（规避豆瓣防盗/Referer 校验）：
  - 本地：`poster = "/static/posters/{movie_id}.jpg"`（以 `/` 开头）→ 前端拼 `BASE_URL`
  - 下载失败兜底：`poster = "https://img…doubanio.com/…"` → 前端直接用
- 前端判断：
```typescript
Image(poster.startsWith('/') ? BASE_URL + poster : poster)
```

**词云 /viz/wordcloud（不是 JSON，直接返回 PNG 字节）**
- `Content-Type: image/png`；前端把**完整 URL 交给 Image**，没有"先取 JSON 再拿地址"的一步：
```typescript
Image(`${BASE_URL}/viz/wordcloud?context=movie:${movieId}&top_n=40`)
  .width('100%').aspectRatio(1.6).objectFit(ImageFit.Contain)
```

> `/static/*` 由后端本地伺服，存的是下载下来的图片；**磁盘目录不入 git**。

## 7. 前端接入指南：把 MOCK 换成真实 HTTP（改 `app/.../services/api.ets`）

当前 `api.ets` 为模板（全部 `TODO` + MOCK 数据）。对照表：

| api.ets 函数 | 真实接口 |
|---|---|
| `crawlMovie(query, source)` | `POST /crawl` body `{source,query,limit:200}` → 轮询 `GET /crawl/{job_id}` 到 done |
| `fetchSentimentDist()` | `GET /dataset/stats?context=movie:{id}` → `dist` |
| `fetchReviews()` | `GET /dataset/reviews?movie_id={id}&limit=…` |
| `fetchKeywords()` / `fetchPolarity()` | `GET /hotspot?context=movie:{id}` → `keywords` / `polarity.{pos,neg}` |
| `fetchTrend()` | `GET /viz/summary?context=…` → `trend` |
| 词云（原组件已删） | `GET /viz/wordcloud?context=…` → **PNG 图片**（Image 加载） |

HTTP 请求示例（ArkTS `@ohos.net.http`）：
```typescript
import { http } from '@kit.NetworkKit';

export function getJSON(path: string, onDone: (code: number, body: string) => void): void {
  const req = http.createHttp();
  req.request(BASE_URL + path, { method: http.RequestMethod.GET }, (err, data) => {
    onDone(err ? -1 : data.responseCode, err ? '' : data.result as string);
    req.destroy();
  });
}
```

联调必做：① App 加 `ohos.permission.INTERNET`；② 本地 http 明文放开；③ `BASE_URL` 填宿主机局域网 IP（模拟器场景见 `app/README.md`）。

## 8. 排错速查

| 现象 | 处理 |
|---|---|
| `/health` `model_ready=false` | `model.msg` 看原因：装 torch / 放 `backend/models/model.pt` |
| `/analyze/zh`、`/backfill` 503 | `.env` 配 `DEEPSEEK_API_KEY` 并 `DEEPSEEK_ENABLED=true` |
| 抓取 `degraded` | 反爬/断网自动走离线样本，`error` 有原因 |
| 词云图打不开 | 后端是否起、URL 是否拼了 BASE_URL、INTERNET+明文权限 |
| 海报显示为豆瓣外链 | 下载失败走了兜底（网络/防盗），不影响功能 |
