# 4_日志与运行说明

## 1. 数据落在哪（爬取的简介与评论）

**全部存本地 SQLite：`backend/data/moodreel.db`**（文件不入 git，成员各自本地一份）。

| 内容 | 表 | 关键字段 |
|---|---|---|
| **影片简介 / 海报 / 评分 / 类型** | `movies` | `intro` / `poster` / `rating` / `genres`（在线抓取成功时由 runner 从豆瓣详情接口顺带写入） |
| **评论（爬取/新增/静态）** | `reviews` | `movie_id`、`source`、`lang`、`text`、`stars`、`pred_label`、`pred_prob`、`model` |
| 抓取任务 | `crawl_jobs` | `status`、`fetched`、`error` |
| 影片基本信息 | `movies` | `movie_id`、`title`、`year`、`source_url` |

常用查看：
```bash
sqlite3 backend/data/moodreel.db "SELECT movie_id,title,rating,substr(intro,1,40) FROM movies;"
sqlite3 backend/data/moodreel.db "SELECT movie_id,source,stars,pred_label,substr(text,1,30) FROM reviews LIMIT 10;"
```

## 2. 日志系统

- **位置**：`backend/logs/moodreel.log`（滚动：单个 5MB × 保留 3 份，目录已 gitignore）
- **级别**：INFO（配置在 `app/logging_config.py` 的 `setup_logging()`）
- **格式**：`时间 级别 模块 内容`
- **设计**：独立 `moodreel` logger（propagate=False，避免与 uvicorn 日志重复），控制台 + 文件双写

### 记录的关键事件

| 事件 | 触发点 | 级别 |
|---|---|---|
| 后端启动 / TextCNN 就绪与否 | `app/main.py` lifespan | INFO / WARNING |
| 抓取任务结果（done/degraded/failed） | `app/crawler/runner.py` | INFO |
| 整片 DeepSeek 补标 | `routers/sentiment.py` `/analyze/backfill` | INFO |
| 手动新增评论入库 | `routers/dataset.py` `/dataset/ingest` | INFO |
| 接口异常 | FastAPI/uvicorn | ERROR |

### 查看

```bash
tail -f backend/logs/moodreel.log        # 实时看
grep -E "ERROR|WARNING" backend/logs/moodreel.log
```
报告/排错引用示例行：
```
2026-09-03 12:00:01 INFO app.main 后端启动完成 model_ready=True
2026-09-03 12:00:05 INFO app.crawler.runner crawl job=… source=douban query=肖申克的救赎 status=done fetched=40
```

## 3. 排错速查

| 现象 | 处理 |
|---|---|
| `/health` model_ready=false | `model.msg` 给原因：装 torch / 放 model.pt |
| 中文情感 503 | `.env` 配置 `DEEPSEEK_API_KEY`（或百度）并 `DEEPSEEK_ENABLED=true` |
| 前端连不上后端 | 同网填宿主局域网 IP；App INTERNET 权限 + http 明文 |
| 抓取 degraded | 反爬/断网走离线样本（日志有原因） |
